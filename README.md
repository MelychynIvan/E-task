# E-task

Local-first Windows focus and task tracking application.

## Product direction

E-task is a lightweight productivity control center built around short focus sessions, a single active task, project → task hierarchy, accumulated time tracking, analytics, skill/experience tracking, and a low-pressure workflow.

## Planned stack

- Tauri 2
- React + TypeScript
- Vite
- SQLite via the official Tauri SQL plugin

## Development status

Initial application scaffold is being prepared. Product decisions live in the project Master Spec and are mirrored into repository guidance through `AGENTS.md`.
